# Java Mini Projects

A collection of small Java applications built while learning and practising core Java concepts, database connectivity, networking, and desktop application development.

The repository brings together independent projects, each focusing on a different aspect of Java programming.

## Projects

### 1. Cricket Stats

A desktop application for managing and viewing cricket player statistics.

- **Technologies:** Java, Java Swing, JDBC, MySQL
- **Concepts:** Database connectivity, SQL operations, GUI development, and data management.

### 2. Chatting Application

A basic client-server chat application that enables two users to exchange messages over a network.

- **Technologies:** Java, Java Swing, Socket Programming
- **Concepts:** Client-server architecture, network communication, and multithreading.

### 3. Notepad Application

A simple text editor developed in Java.

- **Technologies:** Java
- **Concepts:** Desktop application development and text editing.

## Technologies and Concepts

| Area                  | Technologies / Concepts                         |

## Getting Started

1. Clone the repository.
2. Navigate to the project directory you want to explore.
3. Read the corresponding project README.
4. Install the required JDK and any project-specific dependencies.
5. Configure the database or networking settings, if required.
6. Compile and run the application using the documented instructions.

## Purpose

This repository serves as a collection of practical Java projects, documenting the application of programming fundamentals and providing a foundation for further development.
